    インストールと最初の実行

    Composerで導入し、テーブル不要のSQLを1つ実行するまで。

    1. Composerでインストール

    公開配布用の soudai/Laravel-2Way-PostgreSQL をVCSリポジトリとして登録します。以下はLaravelアプリのルートで実行してください。

    bash
    composer config repositories.twoway vcs https://github.com/soudai/Laravel-2Way-PostgreSQL
composer require 'soudai/laravel-2way-postgresql:dev-main'
php artisan vendor:publish --tag=twoway-sql-config

    Packagistへの登録は前提にしていません。現時点では dev-main を指定し、導入したコミットはホストアプリの composer.lock で固定します。ライセンス設定は MIT です。

    パッケージ検出により Hft\TwoWaySql\Laravel\TwoWaySqlServiceProvider が自動登録されます。公開用Composer名とPHP名前空間は異なり、名前空間は Hft\TwoWaySql のままです。

    2. PostgreSQL接続を設定

    既存の config/database.php の pgsql 接続に次のPDOオプションを設定します。接続先・ユーザー等はアプリの通常の環境設定を使用してください。

    php
    'options' => [
    PDO::ATTR_EMULATE_PREPARES => false,
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
],

    PostgreSQL 18/19、UTF8、standard_conforming_strings=on が必要です。実行直前に、Laravelが選択した接続の設定を検証します。compile() とSQLのlintはDBへ接続しません。

    3. SQLファイルを置く

    resources/sql を作成し、resources/sql/value.sql に保存します。テーブルを使わないので、アプリ用のテーブルを追加せずに試せます。

    sql
    SELECT /*:value*/1::bigint AS value;

    SQLクライアントで直接実行すると 1 が返ります。Laravel経由では /*:value*/1 がバインドに変わり、::bigint はSQLに残ります。

    4. SQL IDと入力型を登録

    公開された config/twoway-sql.php の queries を編集します。他の既定設定は保持してください。

    php
    'queries' => [
    'demo.value' => [
        'path' => 'value.sql',
        'kind' => 'read',
        'parameters' => [
            'value' => ['type' => 'int64'],
        ],
    ],
],

    path はSQLルートからの相対パス、kind は読み書きの契約、parameters は入力スキーマです。SQL IDは呼び出し側で使う名前で、ファイル名と一致させる必要はありません。

    5. Laravelから実行

    Laravelがboot済みのController、Service、Console command等で呼び出します。

    php
    use Hft\TwoWaySql\Laravel\Facades\TwoWaySql;

// DB接続せずにSQLとバインドへ変換
$compiled = TwoWaySql::compile('demo.value', ['value' => 7]);

// config/database.php の pgsql 接続で実行
$value = TwoWaySql::connection('pgsql')->scalar('demo.value', ['value' => 7]);
// $value === 7

    connection() を省略するとLaravelの既定接続を使用します。Serviceクラスへ Hft\TwoWaySql\Laravel\TwoWaySqlManager をDIしても同じAPIを呼べます。

    6. SQLを検査してキャッシュ

    bash
    php artisan twoway:lint
php artisan twoway:cache

    成功時は demo.value: OK と表示されます。キャッシュはパラメータ適用前のASTのみで、入力値や検索結果は保存しません。設定をキャッシュしているアプリでは設定変更後に php artisan config:cache も実行してください。
