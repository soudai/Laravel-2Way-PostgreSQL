    設定・オプション一覧

    設定キーの既定値、入力制約、実行オプションを一か所で確認。

    設定ファイル

    php artisan vendor:publish --tag=twoway-sql-config で config/twoway-sql.php を作成します。configはキャッシュ可能な配列・scalar値で管理し、Closureやサービスinstanceは置きません。変更後はアプリのconfig cacheを更新します。

    トップレベルとキャッシュ

    キー 既定値 説明
    root resource_path('sql') SQLルート。実在ディレクトリが必要。symlink不可
    grammar canonical-v1 Laravel統合の既定。別文法は各queryに指定
    queries [] SQL ID → クエリ定義
    limits [] コンパイル・入力予算の正整数による上書き
    cache.path storage_path('framework/cache/twoway-sql') 専用ASTキャッシュディレクトリ
    cache.entries 256 メモリLRUの最大件数。正整数
    cache.bytes 67108864 メモリLRUのJSON換算byte予算（64 MiB）。正整数
    plan_advice [] 信頼済みID → query_id / query_hash / advice

    キャッシュはASTのみです。SQLソースの配布も必要で、結果キャッシュとしては使いません。

    クエリ登録

    キー 必須 / 既定 説明
    path 必須 rootからの相対.sql。各パス部は英数字・underscore・hyphen
    kind 必須 read / locking / write / write_returning
    parameters 必須 入力スキーマ。入力なしなら空配列
    sorts [] text入力の登録ソート定義
    projections [] text入力の登録列選択
    grammar canonical-v1 canonical-v1 または doma-subset-v1
    postgres_min_version 18 整数18または19。実行するPDOで最低版を検証

    SQL IDは小文字の英字で始まる英小文字・数字・underscoreの区切りをdotで連結し、最大128bytes。例は users.search。未知キー、未登録ID、絶対パス、URL、..、symlinkは拒否します。

    php
    'queries' => [
    'users.search' => [
        'path' => 'users/search.sql',
        'kind' => 'read',
        'postgres_min_version' => 18,
        'parameters' => [
            'tenantId' => ['type' => 'int64'],
            'name' => ['type' => 'text', 'nullable' => true],
        ],
    ],
],

    入力の全オプションは パラメータスキーマ、sorts / projectionsは SQL構造の選択 を参照してください。

    処理上限 limits

    値は正整数かつPHP_INT_MAX未満です。0で無効化できません。未知キー、0、負数は TW_LIMIT になります。

    キー 既定値 対象
    template_bytes 1048576 SQLテンプレートのbyte数（1 MiB）
    sql_bytes 8388608 生成SQLのbyte数（8 MiB）
    tokens 100000 字句トークン数
    ast_nodes 100000 ASTと反復展開のnode予算
    depth 32 構造の深さ
    list_items 10000 リストの要素数
    bindings 10000 bind数
    parameter_bytes 8388608 単体パラメータのbyte予算
    total_parameter_bytes 33554432 全パラメータのbyte予算（32 MiB）
    loop_items 1000 ループの入力件数
    loop_iterations 10000 入れ子を含む総反復数
    php
    'limits' => [
    'template_bytes' => 262144,
    'list_items' => 500,
    'loop_items' => 100,
],

    取得結果の全件数やDBのsort領域はこの設定の対象外です。SQLのLIMITや 逐次取得 を使い分けてください。

    診断 diagnostics

    キー 既定値 意味
    coverage false SQL分岐の通過を記録
    execution false 実行時間・行数・errorCode等を記録
    max_sources 128 coverageのsource保持上限
    max_arms 100000 全sourceの分岐保持上限
    max_events 256 実行eventの保持上限

    フラグはbool、上限は正整数です。保持上限を超えると古い記録を破棄します。request/job境界でのclearは 運用ガイド を参照してください。

    テスト接続 testing

    キー 既定値 意味
    connection null 明示したテスト用Laravel接続名
    allowed_hosts [] 接続先hostの完全一致リスト
    allowed_databases [] テストDB名の完全一致リスト
    nonce null markerと照合する32〜128桁のhex値

    通常のselect/executeの接続設定ではなく、checkの実行モード・inspect・explainのための制限です。実DB名・markerを検査します。APP_ENVだけでは許可されません。準備は 隔離DBでの検証 を参照してください。

    コード生成 codegen

    キー 既定値 意味
    root app/Generated/TwoWaySql Laravel basePathからの相対生成先
    namespace App\Generated\TwoWaySql ホストのPSR-4に合わせる生成namespace
    daos [] DAO interfaceのクラス名リスト。最大256件
    parameters [] 入力DTOクラス → 明示入力スキーマ
    results [] SQL ID → 明示結果列スキーマ
    connections [] 登録DAO interface → 接続名またはnull

    rootはアプリ配下に限定され、絶対パス・URL・..・symlinkは不可です。connectionsの省略はLaravel既定接続。結果型はSQLから完全推論せず宣言します。生成手順 を参照してください。

    実行オプション ExecutionOptions

    configのトップレベルキーではなく、呼び出しごとのオブジェクトです。

    php
    use Hft\TwoWaySql\Laravel\Facades\TwoWaySql;
use Hft\TwoWaySql\Laravel\Executor\ExecutionOptions;

$queries = TwoWaySql::connection('pgsql')->withOptions(
    new ExecutionOptions(statementTimeoutMs: 2000, lockTimeoutMs: 100),
);
    引数 既定 許可値 / 効果
    statementTimeoutMs null null=現在値を維持、0=無効化、正整数=ms。最大2147483647
    lockTimeoutMs null 同上。ロック待ち上限
    planAdviceId null null=無効、登録済みID=明示適用。PG19専用

    timeout/adviceを指定した処理はLaravel transaction/savepoint内で設定し、成功時に元へ戻し、失敗時はそのscopeをrollbackします。外側transactionをcommitしません。別reader PDOが選ばれる構成では拒否するため、replica用named connectionを使ってください。

    timeoutは各SQLのDB処理への制約です。batchは各SQL、paginateはCOUNT/dataそれぞれ、eachはDECLARE/FETCH/CLOSEに適用され、PHP callback全体の時間を制限しません。

    BatchOptions / PageRequest

    クラス・引数 既定 許可値
    BatchOptions.atomic true bool。falseは外側transactionなしでのみ利用
    BatchOptions.maxItems 1000 正整数
    BatchOptions.expectedRowsPerItem null nullまたは0以上の整数
    PageRequest.page 1 正整数
    PageRequest.perPage 50 正整数、maxPerPage以下
    PageRequest.maxPerPage 1000 正整数。offsetの整数overflowも検査

    クラスはそれぞれ Hft\TwoWaySql\Laravel\Batch\BatchOptions、Hft\TwoWaySql\Laravel\Pagination\PageRequest です。
